# Scroll Through Blocker

  #### **Functionality:** 
- When you scroll through some mods' UI, there is an annoying bug where while scrolling, you're also zooming the camera
  in and out. Scroll through blocker prevents this camera zoom bleed.
---
#### **Installation:**
- Download the latest release zip file and extract it. Move the 000_ScrollThroughBlocker folder in Gamedata/ to your KSP's gamedata 
directory.
